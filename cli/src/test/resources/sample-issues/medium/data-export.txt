Title: Data Export Functionality

Description:
Users need the ability to export their data in multiple formats (CSV, JSON, PDF). This feature should be accessible from the user dashboard and include progress indicators for large exports.

Acceptance Criteria:
* Support the following export formats:
  - CSV format with headers
  - JSON with proper structure
  - PDF with formatted data
* UI shows progress for exports that take longer than 2 seconds
* Large exports should be processed in the background
* Email notification is sent when background export is complete
* Users can access previous exports for at least 30 days

Tasks:
1. Create ExportService interface and implementations for each format
2. Add export options to user dashboard
3. Implement background processing for large datasets
4. Add email notification service integration
5. Create UI for viewing export history

Priority: MEDIUM

Labels: user-feature, data-management
